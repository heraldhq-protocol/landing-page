# Herald Protocol Context

For Herald protocol documentation, SDK reference, and integration guides, read:
- `HERALD_CONTEXT.md` — comprehensive context file with architecture, SDK, API, specs, and integration patterns
- `content/docs/` — MDX documentation files rendered at /docs/quickstart

The docs are also available via MCP at `POST /api/mcp` (JSON-RPC 2.0 over HTTP).
Tools: `get_herald_context`, `search_herald_docs`, `get_integration_example`, `get_doc_page`.
