---
title: Webhooks
description: Receive real-time push notifications of delivery results and ZK-attestation events.
---

Herald provides outbound webhooks to notify your backend when a notification has been successfully delivered or when a ZK-receipt has been minted on-chain.

### Endpoint Configuration

Webhooks are configured via the Herald Dashboard. Every webhook event includes a signature in the header for verification.

```bash
# Example Header
X-Herald-Signature: t=161454...,v1=9c...
```

### Event Types

| Event | Trigger |
| :--- | :--- |
| `notification.delivered` | The message has been successfully handed off to the provider (SES/TG/SMS). |
| `notification.bounced` | The email bounced back (hard or soft bounce). |
| `notification.failed` | Delivery failed after all retry attempts. |
| `receipt.minted` | The ZK-proof of delivery has been written to the Solana blockchain. |
| `user.registered` | A new user has mapped their public key to a contact channel. |
| `quota.exceeded` | The protocol has exceeded its monthly messaging quota. |

### Managing Webhooks

Webhooks can be managed via the REST API or the [Herald Dashboard](https://app.useherald.xyz).

```bash
# Register a new webhook
curl -X POST https://api.useherald.xyz/v1/webhooks \
  -H "Authorization: Bearer hrld_live_xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://myprotocol.com/webhooks/herald",
    "events": ["notification.delivered", "receipt.minted"]
  }'

# List all webhooks
curl -X GET https://api.useherald.xyz/v1/webhooks \
  -H "Authorization: Bearer hrld_live_xxx"
```

### Security

We recommend verifying the `X-Herald-Signature` header using your webhook secret to ensure the event originated from Herald's Nitro Enclave.

```typescript
import { createHmac, timingSafeEqual } from "node:crypto";

function verifyWebhookSignature(
  payload: string,
  signatureHeader: string,
  secret: string
): boolean {
  const [timestamp, signature] = signatureHeader
    .split(",")
    .map((s) => s.split("=")[1]);

  const signedPayload = `${timestamp}.${payload}`;
  const expectedSig = createHmac("sha256", secret)
    .update(signedPayload)
    .digest("hex");

  return timingSafeEqual(Buffer.from(signature), Buffer.from(expectedSig));
}

// Usage in your webhook handler
export async function POST(request: Request) {
  const payload = await request.text();
  const sig = request.headers.get("X-Herald-Signature") ?? "";
  const isValid = verifyWebhookSignature(
    payload,
    sig,
    process.env.HERALD_WEBHOOK_SECRET!
  );

  if (!isValid) return new Response("Unauthorized", { status: 401 });

  const event = JSON.parse(payload);
  // handle event...
  return new Response("OK", { status: 200 });
}
```

**Note**: Your webhook secret (`whsec_xxx`) is returned when you register a webhook endpoint. Store it securely and never expose it in client-side code.
