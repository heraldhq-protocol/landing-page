We are excited to announce that Herald is officially live on Solana Mainnet. 

### Key Features

* **Privacy Registry**: Integrated locally with Phantom and Solflare.
* **ZK Deliver Receipts**: Low-cost, immutable delivery proofs on-chain.
* **Multi-channel Support**: Email, Telegram, and SMS delivery active.
* **TypeScript SDK**: Version 1.1.0 released for developer integration.

Visit our [Docs](/docs) to start integrating today.
